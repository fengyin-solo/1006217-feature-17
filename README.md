# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 技术供水（cooling）专项规则

技术供水值班入口的规则集中在 `frontend/src/api/cooling-domain.ts`，页面与运营概览共用同一套：

- **收窄**：按系统编号（包含匹配）、供水类型（精确）、压力区间（数值区间）三重收窄；
  可按系统编号、供水压力、滤水器压差排布先后。条件与页码保存在 pinia
  （`stores/cooling-query.ts`，同时持久化到 localStorage），翻页、去运营概览/泄洪页再返回，
  条件保持原样并停在刚才那一页；页码因数据减少越界时收敛到最后一个有效页。
- **两套取值只认一套**：每条系统可能有「登记值（检查日期）」与「运行实测值（运行实测时间）」两套，
  统一以**较晚产生的那一套**为准（实测时间晚于或等于检查日期取实测，否则取登记），
  迁移/保存时即回写为生效值并在「取值来源」标注。压力区间收窄与压力/压差排序共用同一个生效值。
- **异常对账**：异常以「系统状态 = 异常」为唯一事实源。冷却页统计卡与运营概览 cooling 行
  都用 `coolingCounts(rows, 当前收窄条件)` 统计，异常系统数跟着条件变，两边不可能不一致。
- **另存**：导出按当前收窄条件与排布顺序输出，文件名带条数，CSV 行数与页面 total 一致。
- **去重与覆盖**：按系统编号唯一；重复登记整行覆盖为本次版本（不留中间态），不新增第二条。
- **存量迁移**：首次读取 localStorage 时幂等迁移——按检查日期（登记时间）由早到晚重排并按编号去重；
  检查日期早于 2026-09-01 且没有供水类型的，统一归为「机组冷却水（历史遗留）」；
  压力/压差缺项分别按安全值 0.30 MPa、0.04 MPa 回填，全部在「备注」列标注来源。
- **泄洪联动**：异常系统可「列入泄洪待办」，在 flood 模块生成 `FLOOD-COOL-<系统编号>` 的待审批单，
  按系统编号幂等（重复提交只生效一次），泄洪页待审批计数与运营概览待处理数同步变化。
